# MOON для Android

Автономное приложение с игрой внутри APK. Поддерживает Android 8.0+ и Android System WebView/Chrome версии 100 или новее. Текущая сборка нацелена на Android 15 (API 35) и работает на ARM, ARM64 и x86 без отдельных сборок: машинных библиотек в APK нет.

Игровые файлы загружаются из assets через локальный HTTPS-origin WebView, без сервера и сети. Разрешение INTERNET отсутствует. Нативный слой блокирует переходы на внешние адреса и доступ к произвольным файлам. Рекорды остаются в памяти приложения на телефоне; они независимы от рекордов браузерной версии.

При сворачивании игра ставится на паузу. Поворот экрана сохраняет текущий полёт. Полноэкранный режим поддерживается нативным контейнером; кнопка «Назад» закрывает его или предлагает выйти из игры. CSV сохраняется через системный выбор файла без разрешения доступа ко всему хранилищу.

## Сборка в Linux

Требуются Node.js 20+, Python 3.11+ и Java 17+ с модулем `jdk.compiler`.

```sh
cd /workspace/moon
npm test
npm run build:apk
```

Скрипт скачивает официальные Android Platform 35 и Build Tools 35.0.0, проверяя контрольные суммы из официального SDK repository. Можно указать путь к уже установленному SDK через `MOON_ANDROID_SDK`, `ANDROID_HOME` или `ANDROID_SDK_ROOT`. По умолчанию SDK располагается рядом с репозиторием в `moon-android-sdk/`.

Результат: `android/build/MOON-2.0.0.apk` и `android/build/MOON-2.0.0.apk.sha256`. Проверяются подпись APK v2/v3, выравнивание и совпадение всех игровых assets с собранной веб-версией. Папки сборки и подписи исключены из Git.

## Подпись и обновления

Первый запуск создаёт частный ключ в `android/.signing/moon.jks` и пароль в `android/.signing/password.txt`. Эти файлы не публикуются. Сохраните их в защищённом месте: для обновления установленного приложения потребуется тот же ключ. Повторная сборка использует существующий ключ. Для своего ключа с alias `moon` можно задать `MOON_SIGNING_KEYSTORE` и `MOON_SIGNING_PASSWORD_FILE`, не передавая пароль в командной строке.

Перед выпуском следующей версии увеличьте versionCode и versionName в `build.py`, обновите имя публичного APK и его ссылку. Каталог `downloads/` содержит подписанные публичные артефакты; они копируются на GitHub Pages, но не включаются внутрь следующего APK.

## Установка

Откройте ссылку на APK на Android-телефоне, скачайте и откройте файл. Если Android запросит разрешение устанавливать приложения из браузера, разрешите его для этой установки. Игра запускается через иконку MOON и работает без интернета.
