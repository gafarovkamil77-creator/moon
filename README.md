# MOON — симулятор лунной посадки

Браузерное приложение на русском языке, без обязательных внешних зависимостей. Требуется Node.js 20 или новее.

```sh
cd /workspace/moon
npm start
```

Сервер слушает порт 3000 (можно задать `PORT`). Откройте приложение в браузере через адрес сервера. Для проверки модели: `npm test`.

## Возможности

- Двумерный полёт, изменяющаяся масса и расход топлива, лунная гравитация.
- Управление тягой и наклоном ползунками или стрелками; пробел — старт/пауза. При переходе в другую вкладку полёт ставится на паузу.
- Три сценария, редактирование начальных условий, массы, тяги и удельного импульса.
- Телеметрия, графики высоты и скорости, запас Δv, оценка тормозного пути, расход и время работы двигателя.
- Формулы, пояснения и экспорт CSV с интервалом около 0,2 секунды и записью финального касания. Единицы CSV: секунды, метры, м/с, килограммы, проценты, градусы и м/с².
- Мягкая посадка: |vY| ≤ 2 м/с, |vX| ≤ 1 м/с, |θ| ≤ 8°. Целевая площадка: |X| ≤ 40 м. Посадка вне площадки отмечается отдельно.

## Физическая модель

Ось Y направлена вверх, X — вправо. Угол отсчитывается от вертикали, положительный угол отклоняет тягу вправо.

```text
m = mсух + mтопливо
F = Fмакс × тяга / 100
ax = F sin(θ) / m
ay = F cos(θ) / m − g
ṁ = F / (Isp × g0)
Δv = Isp × g0 × ln(m / mсух)
```

Лунная g = 1,625 м/с²; стандартная g0 = 9,80665 м/с² используется в определении удельного импульса. Интегратор выполняет 120 шагов в секунду, использует массу в середине шага и восстанавливает момент контакта с поверхностью внутри шага. Тяга ограничена доступным топливом.

Поверхность плоская; рельеф декоративный. Атмосфера отсутствует. Наклон задаётся напрямую, вращательная инерция не моделируется. Тормозной путь — оценка при текущей массе и наклоне, полном газе и без проверки достаточности топлива на весь манёвр. Симулятор предназначен для обучения.

## Структура

`src/physics.js` — независимая модель; `src/app.js` — визуализация и управление; `style.css` — адаптивный интерфейс; `server.js` — локальный HTTP-сервер; `tests/physics.test.js` — проверки модели.

Разработка идёт в существующем checkout; отдельный Git worktree не требуется. Сборка и установка пакетов не нужны.

## Размещение на хостинге

`npm run build` собирает автономный статический сайт в `dist/`. На хостинг нужно загружать только содержимое этой папки; Node.js на хостинге не требуется. Относительные пути поддерживают публикацию как в корне домена, так и в `/moon/`.

Для GitHub Pages в Settings → Pages выберите Source: **GitHub Actions**. Workflow `.github/workflows/pages.yml` проверяет физическую модель, собирает сайт и публикует его при отправке изменений в `main`. При первом включении Pages для уже отправленного коммита запустите workflow через Actions → Publish simulator to GitHub Pages → Run workflow.

Ожидаемый адрес после успешной публикации: `https://gafarovkamil77-creator.github.io/moon/`. До завершения workflow этот адрес не подтверждён как работающий.
