# MOON — симулятор лунной посадки

Браузерное приложение на русском языке, без обязательных внешних зависимостей. Требуется Node.js 20 или новее.

```sh
cd /workspace/moon
npm start
```

Сервер слушает порт 3000 (можно задать `PORT`). Откройте приложение в браузере через адрес сервера. Для проверки модели: `npm test`.

## Возможности

- Двумерный полёт, изменяющаяся масса и расход топлива, лунная гравитация.
- Управление тягой и наклоном ползунками, стрелками или WASD; пробел — старт/пауза, R — повтор. На телефоне доступны кнопки с удержанием. При переходе в другую вкладку полёт ставится на паузу.
- Пять миссий с разными начальными условиями и шириной площадки, включая точную посадку на площадку ±12 м и спасение с 70 кг топлива. Свободная тренировка с редактированием массы, тяги и удельного импульса.
- Три режима: пилот управляет полностью; помощь автоматически управляет тягой, оставляя наклон пилоту; автопилот управляет обеими осями.
- Темп ½×, 1×, 2× и 4×; физический шаг остаётся 1/120 с при любом темпе.
- Автоматическое приближение камеры, прогноз точки касания, вектор скорости, динамические подсказки, пыль при работе двигателя у поверхности, эффекты посадки и аварии. При `prefers-reduced-motion` декоративные эффекты отключаются.
- Звук двигателя и касания включается вручную, есть полноэкранный режим и встроенная инструкция. Звук условно имитирует звуки внутри аппарата.
- Телеметрия, графики высоты и скорости, запас Δv, оценка тормозного пути, расход и время работы двигателя.
- Формулы, пояснения и экспорт CSV с интервалом около 0,2 секунды и записью финального касания. Единицы CSV: секунды, метры, м/с, килограммы, проценты, градусы и м/с².
- Мягкая посадка: |vY| ≤ 2 м/с, |vX| ≤ 1 м/с, |θ| ≤ 8°. Целевая площадка: |X| ≤ 40 м в первых трёх миссиях, ≤12 м в четвёртой, ≤28 м в пятой. Посадка вне площадки отмечается отдельно.
- Очки, медали, отдельные рекорды пилота и режима помощи, журнал последних шести полётов. Данные сохраняются в localStorage этого браузера. Автопилот и свободные тренировки не устанавливают рекорды миссий; подключение автопилота даже на часть полёта делает весь полёт демонстрационным.

## Оценка посадки

Очки начисляются только за мягкую посадку внутри площадки: 1000 за выполнение миссии, до 1500 за точность, до 1500 за мягкость и до 1000 за оставшееся топливо. Все коэффициенты ограничены интервалом [0, 1].

```text
точность = 1500 × (1 − |x| / полуширина площадки)
мягкость = 1500 × (1 − (|vY| / 2 + |vX|) / 2)
экономия = 1000 × оставшееся топливо / начальное топливо
итог = (1000 + точность + мягкость + экономия) × коэффициент режима
```

Коэффициент режима помощи — 0,65, ручного режима — 1. Рекорды разделены по миссии и режиму. Золото: от 3800 очков; серебро: от 2800; бронза: ниже 2800 за успешную миссию. При изменении параметров текущая миссия становится свободной тренировкой; её очки сохраняются в истории, но не в рекордах стандартных миссий.

## Физическая модель

Ось Y направлена вверх, X — вправо. Угол отсчитывается от вертикали, положительный угол отклоняет тягу вправо.

```text
m = mсух + mтопливо
F = Fмакс × тяга / 100
ax = F sin(θ) / m
ay = F cos(θ) / m − g
ṁ = F / (Isp × g0)
Δv = Isp × g0 × ln(m / mсух)
```

Лунная g = 1,625 м/с²; стандартная g0 = 9,80665 м/с² используется в определении удельного импульса. Интегратор выполняет 120 шагов в секунду, использует массу в середине шага и восстанавливает момент контакта с поверхностью внутри шага. Тяга ограничена доступным топливом.

Поверхность плоская; рельеф декоративный. Атмосфера отсутствует. Наклон задаётся напрямую, вращательная инерция не моделируется. Тормозной путь — оценка при текущей массе и наклоне, полном газе и без проверки достаточности топлива на весь манёвр. Симулятор предназначен для обучения.

Оранжевая траектория и прогноз касания экстраполируют текущее ускорение как постоянное, максимум на 120 секунд. Они не учитывают будущие управляющие действия и изменения массы. После посадки телеметрия показывает момент касания, включая тягу и расход до выключения двигателя.

Автопилот задаёт целевую вертикальную скорость по высоте и управляет боковой скоростью пропорционально расстоянию до цели. Контроллер соблюдает ограничения тяги и топлива; гарантии спасения из произвольной ситуации нет. Тесты проверяют мягкую посадку во всех пяти стандартных сценариях, границы площадки, прогноз, расход топлива и правила очков.

## Структура

`src/physics.js` — независимая модель; `src/game.js` — миссии, автопилот, прогноз и оценка; `src/app.js` — визуализация, управление и журнал; `style.css` — адаптивный интерфейс; `server.js` — локальный HTTP-сервер; `tests/` — проверки физики и игровых правил.

Разработка идёт в существующем checkout; отдельный Git worktree не требуется. Сборка и установка пакетов не нужны.

## Размещение на хостинге

`npm run build` собирает автономный статический сайт в `dist/`. На хостинг нужно загружать только содержимое этой папки; Node.js на хостинге не требуется. Относительные пути поддерживают публикацию как в корне домена, так и в `/moon/`.

Для GitHub Pages в Settings → Pages выберите Source: **GitHub Actions**. Workflow `.github/workflows/pages.yml` проверяет физическую модель, собирает сайт и публикует его при отправке изменений в `main`. При первом включении Pages для уже отправленного коммита запустите workflow через Actions → Publish simulator to GitHub Pages → Run workflow.

Адрес сайта: `https://gafarovkamil77-creator.github.io/moon/`. Изменения становятся доступны после успешного завершения workflow публикации.
